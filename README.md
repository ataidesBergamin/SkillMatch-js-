# SkillMatch-js-

Avaliar a compatibilidade do candidato com as vagas disponíveis.

SkillMatch JS: Simulador de Compatibilidade com Vaga Front-End Júnior

O objetivo do projeto é criar um sistema simples que compare as habilidades de uma pessoa candidata com os requisitos de algumas vagas fictícias de Front-End Júnior.

O sistema compara as habilidades da pessoa candidata com os requisitos de cada vaga disponível e calcula um percentual de compatibilidade, ajudando a identificar quais oportunidades mais combinam com o perfil informado.
O sistema ainda indica quais habilidades a pessoa nescecita aprender, para se qualificar totalmente a vaga almejada.

O projeto foi criado com foco em prática de:

Manipulação de arrays e objetos
Estruturas condicionais
Funções em JavaScript
Lógica de programação
Interação com DOM
Organização de dados
